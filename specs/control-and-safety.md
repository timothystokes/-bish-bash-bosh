# Spec: Control, visibility, safety
- Autonomy: unattended or on-the-loop (visibility + controls). No per-step human gate.
- Terminal TUI first: live log tail, pause/resume/steer, kill switch, cost meter vs budget. No Slack. Web dashboard is not in v1.
- Control channel: `control.json` (pause, resume, steer note injected into next stack, stop), read between iterations. Format `{paused?: boolean, stop?: boolean, steer?: string}`; missing file = running, malformed file = stop (fail closed); a steer note applies to one iteration then is removed; stop wins over pause; the file lives outside the target repo. Kill switch terminates the container. CLI: `hodge control --file <f> pause|resume|stop|steer <note>` merges into the file atomically (refuses a malformed file); `hodge run --control <f>` enables it.
- TUI: `hodge tui --config <f> --control <f> [--repo] [--run-id]` redraws every second (`src/tui.js`): run state, cost/tokens/seconds/iterations vs budget (flags OVER BUDGET), pending steer, tail of the latest iteration transcript. Keys: `p` pause, `r` resume, `s` steer (Enter sends, Esc cancels), `x` stop (needs `y`), `q`/Ctrl-C quit. It only writes via `writeControl`. Kill switch is P3-5.
- Status-source abstraction (`src/status.js` `StatusSource` with `totals`, `lastStatus`, `tail`; `hodge status --config <f> [--repo] [--run-id] [--control <file>]` prints JSON iterations/tokens/cost/seconds vs budgets): run files locally; execution status/history and CloudWatch logs in AWS.
- Secret scanning: small Node preflight-style proxy between agent and model (regex credential rules, redact to `[REDACTED:rule-id]`, nothing forwarded half-inspected, audit log). Implemented in `src/secret-proxy.js`: request and response bodies are buffered whole and redacted; over-limit body (413), upstream error or unwritable audit log (502) => blocked, never forwarded; audit JSONL (`{direction, target, findings:[{rule,count}], blocked?}`) never contains secret values. Metering: with `meterFile` (+ optional `rates`) each response carrying a token `usage` (OpenAI or Anthropic shape) appends `{time, tokens, cost}`; `readProxyUsage` sums it; unwritable meter => blocked. The proxy meter is a cross-check, not added to the budget gate (adapter usage is). Interview usage (`runs/<id>/interview/record.json`) counts in the run-wide budget via `sumRunUsage`. Not yet wired into the CLI (P3-7b).
- Sandbox: Docker container per run locally; Fargate task in cloud.
- Audit log of tool calls.
