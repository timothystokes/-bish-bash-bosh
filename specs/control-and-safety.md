# Spec: Control, visibility, safety
- Autonomy: unattended or on-the-loop (visibility + controls). No per-step human gate.
- Terminal TUI first: live log tail, control-file visibility, seconds and iterations elapsed. No Slack. Web dashboard is not in v1.
- Control channel: `control.json`, format `{paused?: boolean, stop?: boolean, steer?: string}`; missing file = running, malformed file = stop (fail closed); stop wins over pause; the file lives outside the project repo. CLI: `bish-bash-bosh control --file <f> pause|resume|stop|steer <note>` merges into the file atomically (refuses a malformed file); `bish-bash-bosh status`/`tui --control <f>` read it. Neither `bash` nor `bosh` accepts `--control`: the Plan Loop and Build Loop do not consume this file (`specs/modes.md`). Interrupt the local command with Ctrl-C to stop it; there is no container kill command.
- Outer console (O-3, `src/inbox.js`): `bish-bash-bosh console bish|bosh` (operates on the current directory) reads lines from stdin (no model, no run lock, so it runs beside a live loop) and appends each as a bullet to `./more-questions.md` (bish) or `./more-todos.md` (bosh), outside the project repo's tracked content. Known gap: nothing currently consumes `more-todos.md` — the old build loop's inbox integration (`runStep`'s `inboxDir` option) was removed along with it, and neither `bash` nor `bosh` reads it yet; `more-questions.md` is likewise queued but not yet read by the Interview Loop. `test/inbox.test.js` covers only `addEntry`/`consumeInbox`/the console command itself, not loop consumption.
- TUI: `bish-bash-bosh tui --control <f> [--run-id]` (operates on the current directory) redraws every second (`src/tui.js`): run state, seconds/iterations elapsed, pending steer, declared formats, readiness per dimension per spec, QA cycles and findings, done evidence (`src/run-details.js`, read-only from the specs and `runs/<id>/done.json`, `qa-N/` — see the status-source gap noted above: always empty for any run after the build loop removal), tail of the latest iteration transcript. Keys: `p` pause, `r` resume, `s` steer (Enter sends, Esc cancels), `x` stop (needs `y`), `q`/Ctrl-C quit. It only writes via `writeControl`; these control-file updates do not terminate a local loop.
- Status-source abstraction (`src/status.js` `StatusSource` with `totals`, `lastStatus`, `tail`, `details`; `bish-bash-bosh status [--run-id] [--control <file>]`, operating on the current directory, prints JSON iterations/seconds elapsed and `details: {formats, readiness, qa, done}`): run files locally; execution status/history and CloudWatch logs in AWS. `qa`/`done` are read off disk from `runs/<id>/{qa-N/, done.json}` (`src/run-details.js`) but nothing writes either any more since the old build loop's QA cycle and done-verification were removed with it — they are always empty/`null` for any run started after that removal, a known, structurally independent gap.
- Secret scanning: small Node preflight-style proxy between agent and model (regex credential rules, redact to `[REDACTED:rule-id]`, nothing forwarded half-inspected, audit log). Implemented in `src/secret-proxy.js`: request and response bodies are buffered whole and redacted; over-limit body (413), upstream error or unwritable audit log (502) => blocked, never forwarded; audit JSONL (`{direction, target, findings:[{rule,count}], blocked?}`) never contains secret values. Metering: with `meterFile` (+ optional `rates`) each response carrying a token `usage` (OpenAI or Anthropic shape) appends `{time, tokens, cost}`; `readProxyUsage` sums it; unwritable meter => blocked. The proxy meter is a cross-check, separate from adapter usage. Interview usage (`runs/<id>/interview/record.json`) is summed with other run usage via `sumRunUsage` (seconds only; there is no run-wide cap). Run via `bish-bash-bosh proxy --upstream <url> [--audit <f>] [--meter <f>] [--port <n>]` (prints `{port}`, serves on 127.0.0.1 until SIGINT/SIGTERM; no rates flag yet, so cost is metered as 0).
- Execution: local processes with the user's permissions, not isolated. Container and cloud infrastructure are not implemented.
- Audit log of tool calls.
