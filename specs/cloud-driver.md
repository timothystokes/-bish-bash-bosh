# Spec: Cloud driver (AWS)
- **Status: deferred future goal, no infrastructure implementation.** The current harness runs directly on the host (`specs/loop.md`). Container images, the CDK stack, state-machine builder and cloud/container kill switches have been removed at the owner's request. The design below is background only; do not restore infrastructure until the owner promotes this work.
- Infrastructure as code: **AWS CDK**.
- AWS Step Functions loops over `bosh`; each iteration is one Fargate Spot task (`RunTask.sync`) with a fresh context. Lambda is not used for iterations (15-minute cap, no persistent workspace); only for light steps (reading pointers).
- Git and run records are the source of truth. Execution context holds pointers only: commit SHA, iteration, last status, pause/stop flag; it must be rebuildable from git.
- Pause/steer/approval via `waitForTaskToken` or a control record read by a Choice state. There is no run-wide budget: the loop ends only on stop, done, a gated/failed step, or the per-execution iteration cap (successor).
- Kill switch: an external observer calls `StopExecution`. Verify `.sync` also stops the running ECS task.
- History limit (~25,000 events): run N iterations per execution, then start a successor execution with SHA and totals.
- Artifacts to S3, secrets from Secrets Manager. Spot interruption is tolerable: resume from the last commit.
- Pointer rebuilding (previously `rebuildPointers`, `src/bosh-pointers.js`/`src/bosh-read-pointers-handler.js`) was deleted along with `bosh step`'s old build loop and never ported to `bash`/`bosh`'s new Plan/Build Loops: this spec's `$.pointers` contract (`sha`/`iteration`/`status` derived from git + run records) no longer has a matching local implementation to port from. Reconcile this when AWS is promoted, not before.
- Artifacts are synced by the pure `syncArtifacts({client, bucket, repoDir, runId})` (`src/artifacts.js`): `runs/<runId>/**` to the same S3 key, skipping files with an unchanged sha256 (idempotent). Promotion review is `requestPromotion({opener, runId, head, base, artifactsUri, sha})`: opens a PR from the project's branch, never merges, refuses head == base. Real clients live in `src/cloud-clients.js` (`createAwsCliS3Client` over `aws s3api`, sha256 in object metadata; `createGhPrOpener` over `gh pr create`), exposed as `bish-bash-bosh sync --bucket --run-id [--repo <dir>]` and `bish-bash-bosh promote --run-id --head --base --bucket [--sha] [--repo <dir>]` (defaults to the current directory).
