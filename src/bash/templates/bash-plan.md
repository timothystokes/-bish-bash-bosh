# Plan

A prioritised checklist of concrete construction tasks that turn the specification into working software. `-bosh` works through it from the top, one task at a time, ticking each once it is built and verified, so the order of the lines is the build order. Run `-bash` again at any time to re-plan against the code as it now stands.

Each task is one numbered line: `<n>. [ ] T: <name> - <what to build> S: <specification ids>`
